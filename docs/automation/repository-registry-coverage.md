# Repository registry coverage principles

Repository inventory, lifecycle and monitoring coverage are separate from public project presentation. Unknown or unmonitored state must not be interpreted as healthy, obsolete or approved for archival. Monitoring and private operational evidence belong in authorized internal systems. Public documentation should expose only reviewed public project information and relevant interoperability contracts.

See [repository lifecycle](../governance/repository-lifecycle.md) and [source exposure and distribution](../standards/source-exposure-and-distribution.md).
