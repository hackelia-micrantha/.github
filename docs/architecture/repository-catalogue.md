# Repository responsibility and public project catalogue

A repository's visibility and name do not establish its implementation, release or governance authority. Each project's public documentation describes its supported interfaces, maturity, evidence and contribution boundary. A public projection is not automatically an implementation authority, and a laboratory result does not establish production readiness.

See the [public project directory](../../profile/README.md#project-families) and [source exposure and distribution standard](../standards/source-exposure-and-distribution.md). The published directory is intentionally selective; absence is not a claim about project existence, status or support.
