# Public contributor guidance

This public repository contains community documentation, specifications and reviewed reference material. Follow [contribution guidance](CONTRIBUTING.md), [governance](GOVERNANCE.md) and the applicable [engineering standards](docs/standards/README.md). Repository-local requirements may be stricter. Use the smallest useful change, verify behavior or documentation claims, and preserve security and compatibility. Report sensitive findings through the [security policy](.github/SECURITY.md), not public issues or pull requests.

Public documentation does not grant credentials, execution, publication, merge, deployment or approval authority.
